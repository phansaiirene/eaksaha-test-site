# Eaksaha Group website

Website for Eaksaha Group (multi-brand car dealer, Korat), plus the marketing team's board.

- `index.html` – home page (brands, showroom map, promotions, contact)
- `brand.html?b=ford` – one page per brand with models, prices and videos
- `test-drive.html` – test-drive booking (see `CRM-SETUP.md`)
- `admin.html` – marketing board: projects, team activity calendar, Admin claims (see `BOARD-SETUP.md`)

It is a plain HTML/CSS/JS site: open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify).
